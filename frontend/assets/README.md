# Assets Folder

Place your app icons and splash screens here.

## Required Files

- `icon.png` - 1024x1024px (Main app icon)
- `favicon.png` - 48x48px (Browser favicon)
- `splash.png` - 1242x2436px (Splash screen)
- `adaptive-icon.png` - 1024x1024px (Android adaptive icon)

## How to Create Icons

See `docs/ICON_GUIDE.md` for detailed instructions on creating these icons.

## Quick Start

1. Create a 1024x1024px icon design
2. Use an online tool like https://www.appicon.co to generate all sizes
3. Place the generated files in this folder
4. Verify paths in `app.json` match these filenames
